# Фаза 0 — ручные тесты (smoke)

Прогнать перед мержем фазы и после деплоя.

## 1. Гость

- [ ] Открыть `/` — видна главная, баннер «Вы гость» сверху.
- [ ] Кнопки «Зарегистрироваться» / «Войти» — работают.
- [ ] Открыть `/login` — баннера нет.
- [ ] Открыть `/register` — баннера нет.
- [ ] Открыть `/generate` — форма видна, баннер есть.
- [ ] На `/generate` нажать «Сгенерировать» → редирект на `/register?next=/generate`.
- [ ] Открыть `/dashboard` → редирект на `/login?next=/dashboard`.
- [ ] Открыть `/profile` → редирект на `/login?next=/profile`.
- [ ] Открыть `/c/несуществующий` → 404.
- [ ] Открыть `/c/<реальный>` (публичная ссылка) — видно, но нет кнопок «Редактировать», «Сменить».

## 2. Регистрация и вход

- [ ] Зарегистрировать нового пользователя `testuser` с паролем `12345678`.
- [ ] Проверить: в Supabase → Authentication → Users email = `testuser@sagaforge.local`.
- [ ] Войти в `/login` с `testuser` / `12345678`.
- [ ] После входа баннер «Вы гость» пропал.

## 3. Создание кампании

- [ ] Залогиненным открыть `/generate`, заполнить, нажать «Сгенерировать».
- [ ] Кампания создалась, редирект на `/c/<код>`.
- [ ] Открыть `/dashboard` — кампания в списке.
- [ ] Открыть PDF персонажа — футер «SagaForge · кампания <код>».
- [ ] Открыть PDF конспекта мастера — футер «SagaForge · Конспект мастера».
- [ ] Открыть SVG связей — футер «SagaForge · <код>».

## 4. Лимит 10 кампаний

- [ ] Создать 10 кампаний (вручную или скриптом).
- [ ] Попробовать создать 11-ю → ошибка «Вы достигли лимита в 10 кампаний…» (400, не 500).
- [ ] Удалить одну кампанию → 11-я создаётся.

## 5. Полная кампания

- [ ] Создать кампанию с `party_size = 2` (1 мастер + 1 игрок).
- [ ] Залогиниться вторым аккаунтом, зайти по share-ссылке → присоединиться (занять единственное место).
- [ ] Третьим аккаунтом зайти по ссылке → «Кампания заполнена. Все места заняты».
- [ ] Даже invite-код не помогает (создать инвайт → попробовать → ошибка).

## 6. Email после переименования

- [ ] Новый пользователь получает `@sagaforge.local`.
- [ ] Старые `@partyforge.local` — либо удалены, либо обновлены вручную (для тестовых).

## 7. Проверка «no PartyForge»

- [ ] `Select-String -Path "app\*.tsx","app\**\*.tsx","components\**\*.tsx","lib\**\*.ts","lib\**\*.tsx","data\*.ts","docs\*.md","README.md","package.json" -Pattern "PartyForge" -SimpleMatch` — пусто (кроме `docs/audit.md`).

## 8. Сборка

- [ ] `npm run build` — без ошибок.
- [ ] `npm test` — все юнит-тесты зелёные.
