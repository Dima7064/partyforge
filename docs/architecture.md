# Архитектура SagaForge

## Принцип «no free text» (ключевое решение)

**SagaForge не содержит пользовательского текста.** Ни в одном месте интерфейса
нет поля ввода произвольного текста (кроме логина, пароля и заметок мастера —
это не контент, а метаданные). Все данные — из пулов, которые предоставляет
сайт. Пользователь:

- **выбирает** из готовых вариантов (dropdown / radio / multiselect),
- **перегенерирует** (берёт следующий вариант из пула),
- **комбинирует** (multiselect для ценностей/страхов/привычек).

### Что это даёт

- **Нет оскорбительного контента** — его невозможно ввести.
- **Нет спама и рекламы** — некуда вставить.
- **Не нужна модерация** — модерировать нечего.
- **Безопасно по закону** — нет UGC (user-generated content), нет проблем с
  DMCA, нет требований к age verification.
- **Работает офлайн** — весь контент предзагружен.

### Практические примеры

| Поле              | Сейчас (v0)               | В новой версии (Фазы 1+)                                     |
| ----------------- | ------------------------- | ------------------------------------------------------------ |
| Название кампании | `<Input>` free text       | `<Select>` из 30 названий или кнопка «Случайное»             |
| Имя персонажа     | `<Input>` free text       | `<Select>` из пула по расе                                   |
| Предыстория       | `<Textarea>`              | `<RadioGroup>` из 3–5 вариантов                              |
| Характеристики    | 6 полей с числами         | 3 пресета (боевой/сбалансированный/магический)               |
| Ценности          | `<Input>` comma-separated | `<Multiselect>` из 30 пула, max 3                            |
| Страхи            | `<Input>`                 | `<Multiselect>` max 2                                        |
| Привычки          | `<Input>`                 | `<Multiselect>` max 2                                        |
| Мотивация         | `<Input>`                 | `<Select>` из 30                                             |
| Локация           | `<Input>` + `<Textarea>`  | `<Select>` названий + `<Select>` описаний                    |
| Фракция           | `<Input>` + `<Textarea>`  | `<Select>` названий + `<Select>` целей + `<Select>` описаний |
| NPC               | `<Input>` + `<Textarea>`  | `<Select>` имён + `<Select>` описаний                        |
| Ситуация          | `<Textarea>`              | `<Select>` из 8 классических                                 |
| Крючок            | `<Textarea>`              | `<Select>` шаблона + `<Select>` плейсхолдеров                |
| Seed              | `<Input>`                 | `<Select>` из 10 preset + «Случайный»                        |

### Исключения

- **Логин / пароль** — это учётные данные, не контент.
- **Заметки мастера** (`character_notes`) — это личное, не публикуется и не
  показывается другим. Хранится per-user. Модерировать нечего.
- **Код кампании** (`share_code`) — генерируется системой, не вводится вручную.
- **Поиск** (в будущем, `/explore`) — поиск по существующему контенту, не
  создание нового.

## Лимиты (Фаза 0)

- **10 кампаний** на пользователя — общий лимит (мастер + игрок).
  Проверка: `lib/db/limits.ts` → `assertCampaignLimit()`.
- **Полная кампания** — если `COUNT(players) >= party_size - 1`, никто не
  может присоединиться. Invite-коды не работают.
- **Гость** — только чтение. Любое действие → `/register?next=...`.

## Стек

- Next.js 15 App Router, React 19, TypeScript, Tailwind v4
- Supabase (PostgreSQL + Auth), region eu-central-1
- Vercel (hosting), region fra1
- @react-pdf/renderer (PDF), React Flow (граф связей)

## Что НЕ делаем (принципиально)

- **Пользовательский контент** — нет, никогда (см. «no free text»).
- **Комментарии** — нет, никогда. Только оценки (5 звёзд).
- **Чат** — нет, никогда.
- **Модерация** — не нужна, нечего модерировать.
- **Платные API** — нет, только бесплатное (иначе не делаем).
- **Тематические миры** (Скайрим, Ведьмак, etc.) — IP-риск, не делаем.
- **Торговая марка «D&D» в названии** — нельзя. «for D&D 5e» — можно.
